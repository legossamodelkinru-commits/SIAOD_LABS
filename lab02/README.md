# Лабораторная работа 2

Рекурсия, динамический массив, стек и дек. Вариант 19, seed 49.

- `LAB02.py` — реализации и демонстрационные примеры.
- `LAB02_experiment.py` — проверки, замеры и графики.
- `lab02_report.docx` — отчёт.
- `results/lab02/` — результаты запуска на данных варианта.

Для повторения эксперимента в корне репозитория курса с установленным окружением выполни:

```bash
python scripts/generate_data.py --variant 19 --only ops
```

Затем запусти `LAB02_experiment.py` из каталога курса или передай путь к сгенерированным файлам явно:

```bash
python LAB02_experiment.py --variant 19 --data path/to/data/generated
```

`LAB02.py` и `LAB02_experiment.py` должны лежать рядом. Для графиков нужен `matplotlib`.
